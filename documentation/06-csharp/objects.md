# Objects: Living Instances of Classes

## 1. What is an Object?
If a class is the architectural blueprint of a house, an **object** is the physical house built on a specific street.

## 2. Creating an Object in C#
```csharp
Doctor drTanvir = new Doctor();
drTanvir.Id = 1;
drTanvir.BmdcNumber = "BMDC-A-48291";
drTanvir.Qualifications = "MBBS, MD (Psychiatry)";
drTanvir.ConsultationFee = 1500.00m;
drTanvir.IsVerified = true;
```
