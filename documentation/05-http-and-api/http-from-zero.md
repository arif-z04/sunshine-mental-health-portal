# HTTP from Absolute Zero

## 1. What is HTTP?
**HTTP** (HyperText Transfer Protocol) is the conversation format computers use to exchange messages across the web.

## 2. Real-World Analogy: Sending a Letter
* **Envelope**: Contains sender address, recipient address, and stamps (HTTP Headers).
* **Letter inside**: The actual message (HTTP Body / JSON).
* **Mail carrier**: The network router transmitting data packets.
