# HTTP Verbs (Methods) Explained

HTTP verbs express intent:

---

* **`GET`**: Read data safely without changing anything on the server (`GET /api/patient/doctors`).
* **`POST`**: Create a new record or trigger an action (`POST /api/payment/simulate`).
* **`PUT`**: Replace or update an existing record (`PUT /api/patient/profile`).
* **`DELETE`**: Remove a record (`DELETE /api/patient/appointments/5`).
