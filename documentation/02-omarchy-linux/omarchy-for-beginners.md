# Omarchy Linux for Beginners

**Omarchy Linux** is an Arch Linux-based operating system designed for software developers, engineers, and tinkerers.

---

## 1. What is Linux?
Unlike Windows or macOS which are proprietary commercial operating systems developed by single corporations, **Linux** is an open-source operating system kernel created by Linus Torvalds in 1991. Today, Linux powers over 90% of the world's cloud servers, supercomputers, Android phones, and modern developer workstations.

## 2. What Makes Omarchy / Arch Different?
1. **Rolling Release**: You install the OS once, and software packages are continually updated. There is no "version 22.04" or "version 24.04" to wipe and reinstall.
2. **Minimalist Philosophy**: Omarchy does not start unnecessary background bloatware. You decide what runs.
3. **The Arch User Repository (AUR)**: A vast community archive providing installation scripts for almost every software tool in existence.
