# Browser Setup & Web Inspection

## 1. Recommended Browsers
We recommend **Chromium**, **Google Chrome**, or **Mozilla Firefox**:
```bash
sudo pacman -S chromium firefox
```

## 2. Opening Developer Tools
In any browser, press **F12** or `Ctrl + Shift + I`:
* **Console**: Shows JavaScript runtime messages and errors.
* **Network**: Shows HTTP requests sent to `/api/...` and incoming JSON.
* **Application**: Inspects the `sunshine_token` cookie and local storage.
