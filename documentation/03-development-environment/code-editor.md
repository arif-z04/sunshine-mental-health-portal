# Recommended Code Editors

Choose an editor that suits your workflow:

---

1. **Visual Studio Code / VSCodium**:
   - Install: `sudo pacman -S code` (or `yay -S vscodium-bin`).
   - Extensions: *C# Dev Kit*, *PostgreSQL*, *HTML CSS Support*.
2. **JetBrains Rider**:
   - Outstanding professional IDE for .NET and C#.
3. **Neovim / Vim**:
   - For terminal power users using modern LSP plugins (`nvim-lspconfig`, `mason.nvim`).
