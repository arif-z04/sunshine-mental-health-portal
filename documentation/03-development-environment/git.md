# Git Version Control from Scratch

## 1. What is Git?
**Git** is a distributed version control system that records snapshots of files over time so you can recall specific versions later, compare changes, or revert mistakes.

## 2. The Three States in Git
1. **Working Directory**: The actual files you see and edit on your disk.
2. **Staging Area (`git add`)**: The box where you place files marked to be committed in the next snapshot.
3. **Repository (`git commit`)**: The permanent ledger storing the snapshot history forever.

```text
Working Directory  ──( git add )──>  Staging Area  ──( git commit )──>  Local Repository
```
