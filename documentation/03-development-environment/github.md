# Understanding Git Repositories & Remotes

## 1. Git vs. GitHub
* **Git**: The local command-line software tool running on your computer.
* **GitHub**: A cloud-hosting service that stores copies of Git repositories on the Internet so teams can collaborate.

## 2. Essential Commands
* `git status`: Shows which files have been modified or staged.
* `git diff`: Shows exact line-by-line differences between current files and the last snapshot.
* `git log -n 5`: Displays the last 5 commits with author, date, and commit messages.
