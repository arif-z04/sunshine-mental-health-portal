# HTML5 from Scratch

## 1. What is HTML?
**HTML** stands for **HyperText Markup Language**. It is the standard code used to structure a web page and its content.

## 2. Real-World Analogy: The Skeleton
Imagine a human body:
* **HTML** is the **skeleton** (the bones, skull, and ribcage providing physical structure).
* **CSS** is the **skin, clothes, and makeup** (providing color, shape, and appearance).
* **JavaScript** is the **nervous system and muscles** (allowing movement, response, and interaction).

## 3. How Tags Work
HTML elements are surrounded by angle brackets:
```html
<button class="btn-primary" onclick="bookSlot()">Book 16:00 BST</button>
```
* `<button>`: Opening tag.
* `class="btn-primary"`: Attribute configuring appearance.
* `Book 16:00 BST`: Inner text content shown to the user.
* `</button>`: Closing tag.
