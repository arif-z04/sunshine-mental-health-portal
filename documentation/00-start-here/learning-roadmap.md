# Beginner Learning Roadmap

Follow this sequential 7-stage learning journey to master the Sunshine Mental Health Portal:

---

```text
Stage 1: The Basics ──> [01-computer-and-development-basics](01-computer-and-development-basics/what-is-software.md)
                        Learn what servers, clients, APIs, and databases are.

Stage 2: Your OS    ──> [02-omarchy-linux](02-omarchy-linux/omarchy-for-beginners.md)
                        Learn the terminal, pacman, systemctl, and file permissions.

Stage 3: Tooling    ──> [03-development-environment](03-development-environment/prerequisites.md)
                        Install .NET 10, PostgreSQL 18, Git, and set up your editor.

Stage 4: Web Client ──> [04-web-development-basics](04-web-development-basics/html.md) & [05-http-and-api](05-http-and-api/http-from-zero.md)
                        Understand HTML, CSS custom properties, DOM, and HTTP requests.

Stage 5: Backend    ──> [06-csharp](06-csharp/csharp-from-zero.md) & [07-aspnet-core](07-aspnet-core/aspnet-from-zero.md)
                        Learn C# syntax, dependency injection, controllers, and services.

Stage 6: Database   ──> [08-postgresql-and-sql](08-postgresql-and-sql/database-from-zero.md) & [09-entity-framework-core](09-entity-framework-core/ef-core-from-zero.md)
                        Master relational tables, indexes, constraints, and EF Core LINQ.

Stage 7: Mastery    ──> [10-authentication](10-authentication-and-authorization/authentication-from-zero.md) to [15-testing](15-testing/testing-from-zero.md)
                        Learn JWT tokens, password security, automated testing, and deployment.
```
