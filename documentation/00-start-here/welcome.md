# Welcome to Sunshine Mental Health Portal

Welcome to the **Sunshine Mental Health Portal** engineering and learning documentation.

If you have never written a full-stack web application, never configured a relational database, or never used the Linux terminal before, **you are in the right place**.

---

## What is This Documentation?
This is not a dry reference manual written only for senior architects. It is a **complete beginner-to-project-developer learning guide** designed to teach you how modern software works using this real-world, production-ready healthcare application as our working laboratory.

You will not find unexplained technical jargon or hand-waving here. Every single concept is explained using:
1. **Plain, everyday language**.
2. **Intuitive real-world analogies** (restaurants, kitchens, libraries, post offices).
3. **Exact code snippets** taken directly from this repository.
4. **Concrete commands** you can copy, paste, and run on your Omarchy Linux workstation.

---

## What is the Sunshine Mental Health Portal?
Sunshine is a telehealth and psychological counseling platform engineered specifically for the healthcare, financial, and cultural environment of **Bangladesh**:
* **Certified Specialist Directory**: Vetting psychiatrists (MBBS, MD, FCPS) and clinical psychologists.
* **Evening Telehealth Consultations**: 45-minute slots from 16:00 to 20:30 Bangladesh Standard Time (BST, UTC+06:00).
* **Local Payment Channels**: Instant mobile booking deposits via **bKash (বিকাশ)**, **Nagad (নগদ)**, and **Rocket (রকেট)** in Bangladeshi Taka (৳ BDT).
* **Emergency Crisis Support**: Immediate, zero-latency links to national hotlines like **কান পেতে রই (Kaan Pete Roi)**, **999**, and **16263**.
* **Self-Help Vault**: Bengali and English psychoeducation articles and Cognitive Behavioral Therapy (CBT) workbooks.
