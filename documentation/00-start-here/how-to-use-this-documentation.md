# How to Use This Documentation

This guide explains how to get the most value out of these documents whether you are learning to code, preparing for an exam, or onboarding as a software engineer.

---

## 1. Structure of Every Lesson
Each technical lesson in this documentation is organized into 9 consistent parts:
1. **What is it?** A simple, jargon-free definition.
2. **Why does it exist?** The real problem software engineers faced before this tool was invented.
3. **Real-world analogy**: A non-technical comparison (e.g. why an API is like a restaurant waiter).
4. **How it works**: Step-by-step mechanical breakdown.
5. **How it is used in Sunshine**: The specific role this tool plays in our healthcare platform.
6. **Where to find it in the repository**: Exact file paths you can open and inspect.
7. **Code Example**: A clear snippet with line-by-line explanations.
8. **Common beginner mistakes**: Traps that trip up newcomers and how to avoid them.
9. **Connection to the next concept**: How this lesson bridges into the next topic.

---

## 2. Recommended Reading Modes

* **Path A: The Absolute Beginner (Never coded before)**
  Start at `00-start-here/`, then `01-computer-and-development-basics/`, then `02-omarchy-linux/`. Do not skip chapters.
* **Path B: The Code Learner (Knows Python/JS, new to C# & .NET)**
  Skim Chapter 01, complete Chapter 03 (Omarchy Setup), and dive into Chapter 06 (C#) and Chapter 07 (ASP.NET Core).
* **Path C: The System Administrator / DevOps**
  Jump to Chapter 03 (Omarchy Linux), Chapter 04 (PostgreSQL), Chapter 14 (Deployment), and Chapter 15 (Testing).
