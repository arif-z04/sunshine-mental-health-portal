# Software Engineering & Healthcare Glossary

Key terms explained for beginners:

---

* **API (Application Programming Interface)**: A standardized contract allowing different software applications to communicate.
* **BST (Bangladesh Standard Time)**: UTC+06:00, the official timezone of Bangladesh.
* **BMDC**: Bangladesh Medical and Dental Council, the official regulatory body licensing doctors in Bangladesh.
* **CBT (Cognitive Behavioral Therapy)**: Evidence-based psychotherapy identifying and reframing negative thinking patterns.
* **DTO (Data Transfer Object)**: A simple data structure used to transfer data between client and server without exposing database entities.
* **EF Core (Entity Framework Core)**: Object-Relational Mapper that maps C# classes to PostgreSQL relational tables.
* **IDOR (Insecure Direct Object Reference)**: A security flaw where an application exposes a reference to an internal object (e.g. an appointment ID) without validating ownership.
* **MFS (Mobile Financial Services)**: Mobile wallet platforms ubiquitous in Bangladesh (bKash, Nagad, Rocket).
* **PBKDF2**: Cryptographic password hashing function designed to resist brute-force cracking.
* **RBAC (Role-Based Access Control)**: Restricting system access based on user roles (`PATIENT`, `DOCTOR`, `ADMIN`).
