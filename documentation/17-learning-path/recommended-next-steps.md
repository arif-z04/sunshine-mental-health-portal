# Recommended Next Steps for Students & Engineers

Hands-on exercises to expand your engineering skills:

---

1. **Exercise 1: Add a Doctor Rating System**
   - Create a table `doctor_ratings` with columns for stars (1-5) and feedback comments.
   - Add an endpoint `POST /api/patient/appointments/{id}/rate`.
   - Display average ratings on doctor cards.

2. **Exercise 2: Implement SMS Notifications via Twilio or SSLWireless**
   - Integrate an SMS gateway to send real SMS reminders to patient phone numbers 1 hour before scheduled consultation time.

3. **Exercise 3: Deploy to a Raspberry Pi or Cloud VPS**
   - Follow Chapter 14 to deploy Sunshine onto an Arch Linux VPS or local server with Nginx and Let's Encrypt SSL.
