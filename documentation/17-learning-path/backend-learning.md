# Backend Learning Guide (C# & ASP.NET Core)

Key concepts to master in the backend:

---

1. **Dependency Injection**: Learn how interfaces (`IAppointmentService`) decouple controllers from service implementations.
2. **Async Programming**: Master `async` and `await` with `Task<ActionResult<T>>` to build non-blocking web servers.
3. **Data Annotations & Records**: Use C# records for immutable DTOs and validation attributes (`[Required]`, `[EmailAddress]`).
