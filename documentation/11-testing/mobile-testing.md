# Mobile Responsive Testing

Validating usability on mobile viewports.

---

## 1. Tested Viewport Dimensions
* **320px** (Compact mobile - iPhone SE legacy)
* **375px** (Standard mobile - iPhone 12/13/14)
* **390px** (Modern mobile - iPhone 15/16)
* **414px** (Large mobile - Plus / Max models)

## 2. Mobile Checklist
* [ ] Navigation drawer opens cleanly via hamburger button without pushing page content off-screen.
* [ ] No horizontal scrolling or content clipping (`overflow-x: hidden`).
* [ ] Specialist cards stack vertically into a single column.
* [ ] Booking slot chips wrap comfortably without overlapping.
* [ ] Touch targets are at least 44x44 pixels.
