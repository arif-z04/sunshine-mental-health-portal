# Web Accessibility (a11y) Standards

Ensuring the portal is accessible to all users, including individuals experiencing anxiety or physical impairments.

---

## 1. Core Accessibility Features
* **Color Contrast**: All text satisfies WCAG AA contrast ratio (> 4.5:1 against background surfaces).
* **ARIA Attributes**: Modals and dropdowns use `aria-expanded`, `aria-hidden`, and `role="dialog"`.
* **Keyboard Navigation**: All interactive elements (buttons, inputs, tabs) are reachable and operable via the `Tab` and `Enter` keys.
* **Readable Typography**: System sans-serif fonts (`Inter`, `Segoe UI`, `Roboto`) rendered with clean line heights (`1.5` to `1.6`).
