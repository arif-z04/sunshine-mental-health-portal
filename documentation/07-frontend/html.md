# Semantic HTML5 Structure

Semantic HTML ensures clean visual hierarchy, search engine optimization (SEO), and screen reader accessibility.

---

## 1. Semantic Tag Usage
* `<header>`: Contains the application brand bar, Bangladesh emergency crisis banner, and navigation drawer toggle.
* `<nav>`: Hosts navigation links and authentication action buttons.
* `<main>`: Wraps primary interactive tabs (e.g. Specialists, Appointments, Vault, Profile).
* `<section>`: Isolates functional areas (e.g. Hero banner, FAQ accordion).
* `<dialog>` / Modal overlays: Renders interactive dialogs (bKash payment checkout, reschedule picker).
* `<footer>`: Disclaims medical emergency warnings and lists institutional mental health contacts.
