# Reusable UI Components

The portal features modular UI components implemented in pure HTML and CSS:

---

## 1. Doctor Specialty Card
Renders doctor photo/avatar, BMDC credentials, degrees (MBBS, MD), practice fees in BDT (`৳1,500`), and a "Book Session" call-to-action button.

## 2. MFS Payment Modal
Simulates the bKash/Nagad checkout overlay with brand logos, payment summary, 11-digit phone number field, and PIN entry.

## 3. Bangladesh Crisis Alert Banner
Sticky top banner with emergency red highlight, directly clickable phone links (`tel:+8801779554391`), and emergency service badges (`999`, `16263`).

## 4. Toast Notifications
Lightweight floating toast alerts at the bottom right corner providing instant feedback for successes ("Appointment confirmed!"), warnings, or errors.
