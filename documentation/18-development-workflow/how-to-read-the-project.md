# How to Read the Codebase

A guide for beginners opening this repository for the first time:
1. Start at `server/Sunshine.App/Program.cs` to see registered services and middleware.
2. Read `Models/Entities.cs` to understand the domain data model.
3. Inspect `Controllers/` to see available API routes.
4. Read `Services/` to study business logic implementation.
5. Check `wwwroot/` to see how the frontend renders the UI.
