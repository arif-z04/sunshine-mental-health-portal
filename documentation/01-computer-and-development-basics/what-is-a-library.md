# What is a Library?

## 1. What is it?
A **library** is a reusable collection of functions or routines that your code can import and call to perform specific tasks without writing the logic from scratch.

## 2. Framework vs. Library
* **Library**: You are in the driver's seat. You decide when to call the library (e.g. `BCrypt.Net` or `xUnit`).
* **Framework**: The framework is the driver's seat; it hosts your code inside its lifecycle (e.g. `ASP.NET Core`).
