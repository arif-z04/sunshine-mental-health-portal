# Dictionary of Common Development Terms

Essential developer vocabulary defined for beginners:

---

* **Bug**: An error or flaw in software causing it to produce an unintended result.
* **Refactoring**: Restructuring existing computer code without changing its external behavior.
* **Environment**: The computer ecosystem where software runs (e.g. *Development* on your laptop vs. *Production* on a live Linux server).
* **Localhost**: The networking nickname meaning "this current computer" (IP address `127.0.0.1`).
* **Port**: A numbered virtual doorway on a computer where specific network services listen (e.g. Web server on port `5000`, PostgreSQL on port `5432`).
* **DNS (Domain Name System)**: The phonebook of the Internet translating names like `sunshine.org` into numeric IP addresses.
* **Payload**: The core data being transmitted inside an HTTP request or response.
