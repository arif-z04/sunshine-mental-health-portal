# What is JSON?

## 1. What is it?
**JSON** stands for **JavaScript Object Notation**. It is a lightweight, human-readable text format used to exchange structured data between servers and browsers.

## 2. Example from Sunshine
```json
{
  "id": 1,
  "fullName": "Dr. Tanvir Ahmed, MBBS, MD",
  "specialization": "Adult Psychiatry",
  "consultationFee": 1500.00,
  "currency": "BDT",
  "isVerified": true
}
```
* Text inside quotes (`"id"`, `"fullName"`) are **keys**.
* Values can be numbers (`1500.00`), strings (`"BDT"`), booleans (`true`), or arrays (`[...]`).
