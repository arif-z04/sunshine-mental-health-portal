# What is a Website?

## 1. What is it?
A **website** is a collection of publicly accessible, interlinked web pages that share a single domain name and are hosted on a web server connected to the Internet.

## 2. Static vs. Dynamic Websites
* **Static Website**: Every visitor sees the identical text and images because the HTML file is pre-written on disk.
* **Dynamic Web Application (Sunshine)**: Different visitors see completely different data depending on who is logged in. When patient *Anika* opens the portal, she sees her upcoming appointments. When *Dr. Tanvir* opens the portal, he sees his clinical patients and consultation ledger.
