# ASP.NET Core 10 from Scratch

## 1. What is ASP.NET Core?
**ASP.NET Core** is Microsoft's high-speed, cross-platform, open-source web framework for building modern web applications and REST APIs in C#.

## 2. Why ASP.NET Core 10?
* **Performance**: Consistently ranks among the fastest web frameworks in the world (TechEmpower benchmarks).
* **Reliability**: Strong typing catches errors at compile time before code ever runs in production.
* **Cross-Platform**: Runs natively on Omarchy Linux under Kestrel.
